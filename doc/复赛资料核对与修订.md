## 路线和参数依据

路线：右上起点 → 上路向西 → 西路向南至中间横支路 → 横支路向东 → 中路向南 → 底路向东 → 东路向北，沿途识别 1/2/3 号车牌 → 返回起点。观察过程允许在路内转向。

`地图-图.png` 和任务示意图并非同一比例的测绘图，斑马线长度、停止线位置及 B 区分隔等画法存在差异。本版按地图拓扑、明确的 0.60 m 标注及任务箭头统一建模；未标尺寸的坐标属于仿真归一化取值。起终点区域按任务箭头允许横向进出。`field_layout.png` 是生成器画出的审核示意，不是 Gazebo 截图。

外围实体墙是此前用户要求，予以保留；新增资料没有给出墙高和厚度。人偶的精确高度、每个槽位对应哪张身份图、灯架前后厚度和脚座长度、车牌安装高度、灯周期均没有明确数值，已在 `config/scene_manifest.json` 标明。默认每区 4 名社区人员和 1 名非社区人员是演示配置；不能把素材库的 18 张图当成场上 18 人。

## 视觉基线的能力边界

算法仅使用相机图像与提供的素材库：ORB 特征匹配 → RANSAC 单应性 → 透视纠正后的外观相似度 → 连续两帧确认。人物透明背景不参与外观相关性评分，避免黑色地面影响；较远背景人物不计入当前街区统计。暗灯不会当作亮灯，没有检测或灯色冲突输出 `unknown`。

这是一套固定素材的闭集识别基线。车牌字符由识别到的官方模板映射输出，**不是通用字符 OCR**；置信度为相似度，未做概率标定。当前统计按“街区＋身份”去重，同一身份若摆多张立牌会少计，需要实例跟踪才能适配。默认场景没有重复身份。

每个新结果的终端 JSON 包含类别、内容、置信度、编号、原图时间戳和对应截图路径；图中标同一编号和置信度，`/vision/annotated` 保留原图 header。最终统计只计算实际识别到的身份和牌号。默认 A/B 各 5 个唯一身份且 3 张牌才通过覆盖检查。
